1. ¿Qué es HTML?

HTML (HyperText Markup Language, «lenguaje de marcado de hipertexto») es el lenguaje estándar que se usa para describir la estructura y el contenido de las páginas web: títulos, textos, imágenes, enlaces, listas, tablas y formularios.

Hipertexto

Texto que contiene enlaces hacia otros textos, páginas o sitios. Permite recorrer la información sin un orden fijo.

Marcado

El contenido se rodea con etiquetas que indican qué es cada parte: un título, un párrafo, una imagen o un enlace.

Lenguaje

Tiene reglas de escritura (sintaxis) que el navegador sabe leer e interpretar para mostrar la página.

1991Tim Berners-Lee describió los primeros elementos de HTML a inicios de los años 90.
HTML5Versión actual del estándar, mantenido por el W3C y el WHATWG.
.htmlExtensión de los archivos. No es un lenguaje de programación: describe el contenido, no calcula.

1. ¿Qué es HTML? Cómo funciona

El navegador lee el archivo de arriba hacia abajo, interpreta cada etiqueta y dibuja la página. Una página web se forma con tres lenguajes que trabajan juntos:

HTML

Estructura. Define qué contenido hay y cómo se organiza. Es el esqueleto de la página.

CSS

Presentación. Define el aspecto: colores, tipos de letra, tamaños y distribución.

JavaScript

Comportamiento. Hace que la página responda: menús, formularios, animaciones.

2. Qué software se necesita para escribir código HTML

1. Editor de texto

Programa donde se escribe y se guarda el código. Un editor para código pinta las etiquetas de colores, sugiere los cierres y ayuda a detectar errores. Incluso el Bloc de notas sirve, si se guarda como .html.

Visual Studio CodeNotepad++Sublime Text

2. Navegador web

Programa que interpreta el HTML y muestra la página. Conviene probar en más de uno. Incluye las herramientas del desarrollador (tecla F12) para ver el código y buscar errores.

Google ChromeMozilla FirefoxMicrosoft Edge

3. Complementos

Opcionales. Ayudan a trabajar más rápido y a publicar la página. Algunos funcionan como extensión del editor.

Live ServerGit y GitHubEditor de imágenes
Mínimo necesario: un editor de texto y un navegador. Hay opciones gratuitas, como Visual Studio Code y Notepad++, y los navegadores indicados también lo son.

3. El código de la primera página, línea por línea

index.html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola, mundo</h1>
  <p>Mi primera página en HTML.</p>
</body>
</html>
CódigoQué hace
<!DOCTYPE html>Declara que es un documento HTML5.
<html lang="es">Elemento raíz. «es»: idioma español.
<head>Información de la página que no se muestra.
<meta charset="UTF-8">Codificación: tildes y ñ correctas.
<title>Título que aparece en la pestaña.
<body>Todo el contenido visible.
<h1> y <p>Título principal y párrafo de texto.

4. HTML básico: estructurar texto con etiquetas

Atributos
<img src="foto.jpg" alt="…">
Pares nombre="valor" dentro de la etiqueta de apertura.
Anidación
<p><strong>Texto</strong></p>
Se cierra primero la etiqueta que se abrió al final.
Etiquetas vacías
<br> <hr> <img>
No llevan contenido ni etiqueta de cierre.
Comentarios

No se muestran en la página. Sirven para documentar.

5. Estructura interna de una página web

<!DOCTYPE html> <html lang="es">
<head> · no se ve
<meta charset="UTF-8"><title>Mi sitio</title><link rel="stylesheet" href="estilos.css"><script src="app.js"></script>
<body> · sí se ve
<h1> títulos, <p> textos<img> imágenes, <a> enlaces<ul> listas, <table> tablas<form> formularios

<html> y DOCTYPE

El DOCTYPE indica la versión de HTML. El elemento html envuelve toda la página; lang declara el idioma.

<head>: información

Datos sobre la página: codificación, título de la pestaña, hojas de estilo (CSS) y scripts (JavaScript).

<body>: contenido

Todo lo que el visitante ve y usa: textos, imágenes, enlaces, listas, tablas y formularios.

5. Etiquetas semánticas: organizar el body

<header>
<nav>
<main><section> / <article>
<aside>
<footer>
EtiquetaSe usa para
<header>Encabezado: logo y título del sitio.
<nav>Menú de navegación con enlaces.
<main>Contenido principal (uno por página).
<section>Sección temática del contenido.
<article>Contenido independiente (noticia, entrada).
<aside>Contenido complementario, barra lateral.
<footer>Pie de página: autor, contacto, derechos.

Ventajas: código más ordenado, mejor lectura con lectores de pantalla y mejor comprensión por los buscadores.

6. Cómo incluir videos, audio y gráficos

Video

Etiqueta video. El atributo controls muestra los botones de reproducción.

<video src="video/clase.mp4"
       controls width="480">
</video>

Audio

Etiqueta audio, con los mismos controles de reproducción.

<audio src="audio/intro.mp3"
       controls>
</audio>

Gráficos

svg: dibujos vectoriales. canvas: se dibuja con JavaScript.

<svg width="120" height="60">
  <rect width="120" height="60"
        fill="#46D6EB"/>
</svg>

Contenido externo

iframe inserta un video, un mapa u otra página.

<iframe src="https://..."
        width="480" height="270"
        title="Video">
</iframe>

Atributos útiles
  • target="_blank": abre en otra pestaña.
  • rel="noopener": seguridad al abrir en otra pestaña.
  • title: texto de ayuda al pasar el cursor.
  • download: descarga el archivo.

7. La importancia de los hipervínculos

Por qué son importantes
  • Son la base de la web: conectan páginas y sitios entre sí.
  • Permiten navegar y recorrer el contenido sin orden fijo.
  • Ayudan a los buscadores a descubrir y relacionar páginas.
  • Organizan el sitio y mejoran la experiencia de uso.
Buenas prácticas
  • Usar textos descriptivos («Ver contacto») y no «clic aquí».
  • Revisar que los enlaces no estén rotos.
  • Usar rutas relativas para las páginas del mismo sitio.
  • Avisar si el enlace se abre en otra pestaña.

8. Cómo lanzar la página web online

1

Elegir un hosting

Servicio que guarda los archivos y los mantiene disponibles en internet.

2

Subir los archivos

Se sube la carpeta completa: index.html, estilos, imágenes y demás archivos.

3

Obtener la dirección

El servicio entrega una URL. Opcionalmente se compra un dominio propio.

4

Probar la página

Abrir la URL desde otro equipo y desde el celular. Revisar enlaces e imágenes.

8. Hosting, dominio y revisión final

OpciónCaracterísticas
GitHub PagesPublica sitios estáticos desde un repositorio de GitHub. Opción gratuita.
NetlifySe arrastra la carpeta del sitio y queda publicada. Tiene plan gratuito.
Cloudflare Pages / VercelPublicación automática desde un repositorio. Tienen planes gratuitos.
Hosting tradicionalServicio de pago con panel de control. Incluye correo y base de datos.

Dominio: dirección propia (por ejemplo, mipagina.com) que se paga por año. Los servicios gratuitos entregan una dirección como usuario.github.io.

Lista de revisión antes de publicar
  • El archivo principal se llama index.html.
  • Las rutas de imágenes y enlaces son correctas.
  • Las imágenes están optimizadas (livianas).
  • La página se ve bien en varios navegadores y en el celular.
  • Todos los enlaces funcionan.
